# Security Policy

## Scope

This repository contains a defensive or educational software project. Use it
only in systems, networks, data, and devices that you own or are explicitly
authorized to test.

## Reporting a Vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Contact
the repository owner through the GitHub profile:

https://github.com/Abdulrahman-Alsebaeai

Include the affected component, reproduction steps, impact, and any suggested
mitigation. Do not include credentials, personal data, or live exploit
payloads.

## Secrets

Never commit API keys, passwords, tokens, private model files, production
database exports, or real user data. Revoke any secret that is accidentally
committed and remove it from the repository history before publishing a new
release.
