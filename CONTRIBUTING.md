# Contributing

This repository is maintained as a portfolio and engineering project.

## Before opening a change

- Read the project README and the relevant documentation.
- Keep changes focused and explain the user or engineering problem solved.
- Do not commit secrets, generated runtime data, private datasets, or local
  environment files.
- Preserve Arabic/English localization and RTL/LTR behavior where applicable.
- Add or update tests and documentation for behavior changes.

## Pull requests

Include a concise summary, validation steps, screenshots for UI changes, and
any migration or configuration notes. Security-sensitive behavior should be
reviewed carefully and must not weaken authorization, privacy, or safe-demo
boundaries.
